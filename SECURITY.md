# Security policy

A public listing is not a safety guarantee. Admission review records identity, provenance, manifest bytes, declared paths/hashes, and review scope. It cannot prove code is harmless.

Do not submit credentials, private URLs, or executable validation workflows. CI performs bounded local document validation only and has no write token or provider-network access.

For a suspected malicious entry or directory compromise, use GitHub's private vulnerability reporting for this repository when available. If private reporting is unavailable, contact a FrilLab repository maintainer through GitHub before publishing details. Maintainers should suspend an affected entry promptly, preserve its Git history, investigate immutable provenance, and publish a reviewed correction or rollback.
